# V6 Brand System — Schmiddi & Schreier Spezial

## Visual direction
- Royal / classic blue as the primary game surface
- Glossy red as the main action color
- Cream-white dice and score paper
- Gold used sparingly for highlights, status, and premium details
- The score block keeps the familiar paper/game-sheet feeling, but uses blue lines and red active states
